# ✦ Sami's Scent — Luxury Perfume Store

A beautifully crafted web application for **Sami's Scent**, a luxury perfume store.
Built with **HTML, CSS, JavaScript, and Python (FastAPI)** with **Resend** email integration.

## 🌟 Features

- 🎨 **Elegant UI** with advanced animations and mature color palette
- 🌓 **Auto Light/Dark Theme** — detects user's device preference automatically
- 👤 **CEO Showcase** — circular profile with floating rings, orbs, sparkles & tilt effect
- 📱 **Social Integration** — WhatsApp, TikTok, Instagram, Telegram, and online shop
- 📧 **Newsletter Subscription** — powered by Resend with beautiful welcome emails
- ✨ **Smooth Animations** — scroll reveals, particle backgrounds, hover effects
- 📱 **Fully Responsive** — looks stunning on all devices
